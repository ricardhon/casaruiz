Pedido de diagnóstico

As perguntas certas, antes de começarmos.

Isto não é burocracia — é a primeira camada do diagnóstico. Seis minutos a preencher, e algumas destas perguntas vão fazê-lo olhar para coisas que ainda não tinha olhado.

01A empresa
Se ainda não existe, escreva "não tem". É um dado tão útil como o endereço.
Cidade, distrito ou região. A área geográfica muda toda a estratégia local.
Não o mais conhecido — o de maior margem. É frequentemente o pior posicionado.
02Como chegam os clientes hoje
Escolha as principais.
Um número aproximado chega. Se nunca contou, escreva isso — também é uma resposta.
03A concorrência
Aqueles que o incomodam quando pesquisa o seu próprio serviço. São a base da análise comparativa.
Cada vez mais clientes começam a procura aqui, e não no Google.
04Contexto e decisão
Agências, campanhas, site novo, freelancers. Saber o que não funcionou evita repetir o caminho.
05Contacto

Resposta no próximo dia útil. Os dados servem apenas para responder a este pedido e não são partilhados com terceiros.
